# Sample applications

Every startup, founder and number in this folder is **fictional**. Paste one into the `#brief-desk` (or `#desk-live`) channel to run the desk.

| File | What it shows |
| --- | --- |
| `khetora.txt` | The full demo: a missing field, a WhatsApp follow-up, contradictions for "Questions an investor will ask", and personal details for privacy to strip. Reply to intake with the use of funds in `khetora-followup.txt` |
| `kisankart.txt` | A clean run, plus the analyst adding a detail that privacy catches |
| `medisaathi.txt` | Personal details hidden in free text, and a request to hide the company name |
| `orbitkraft.txt` | No investor in the list fits, so matcher says so instead of forcing a match |
| `paysetu.txt` | Credit tracked through the app is not revenue, and every agent keeps it that way |
| `skillsetu.txt` | A strong fit with two clean investor matches |

Running a real application? Start the message with `@intake REAL: new application:`. Every file for it then stays in `private/`, which is git-ignored.
